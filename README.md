#Function calculator

A C++ console application designed to compute a mathematical function over a
specified range of arguments input and output.

#Overview

This project was developed following the **Waterfall SDLC model** (Requirements Analysis → System Design → Implementation → Testing → Deployment).
The program reads calculation parameters from an input file,validates the data, evaluates the mathematical function, and saves the formatted results to an output file.


#  Features
 *File Input/Output: Automatically reads initial parameters from `input.txt` and writes calculated values to `results.txt`.
 *Error & Edge-Case Handling:** Validates file availability and prevents invalid mathematical operations (such as division by zero or out-of-domain values).
 *Console Interface:** Displays execution status and calculation progress directly in the terminal.
